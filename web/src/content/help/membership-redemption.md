# 使用会员兑换码

会员兑换码采用 `WZM-XXXX-XXXX-XXXX-XXXX-XXXX` 格式，每个码只能成功使用一次。

## 兑换前提

你需要登录已验证邮箱的 WenzWork 账户，再进入“账户中心 → 会员权益”提交兑换码。内测赠送码与领取邮箱绑定，只能由该邮箱对应的 WenzWork 账号兑换；每个邮箱只能使用一次内测码，永久会员不能使用。请勿在聊天、截图或公开工单中发送完整兑换码。

## 有效期怎样计算

- 当前没有有效 Pro 会员时，从兑换成功时间开始计算；
- 当前 Pro 会员仍有效时，在现有到期时间之后顺延；
- 长期会员不会因兑换较短方案而被降级。

## 兑换失败怎么办

先检查是否误输入了字符，兑换码是否已过期、撤销或使用，以及内测赠送码的领取邮箱是否与当前账号一致。确认当前账户已经验证邮箱；会话过期时请重新登录后再试。出于安全考虑，完整兑换码不会保存到浏览器，也不会写入普通应用日志。

兑换成功后页面会重新读取会员状态和有效期。若结果没有更新，不要连续重复提交；先刷新会员中心，再通过页面列出的联系方式提供邮箱、发生时间和错误提示，切勿提供完整兑换码。
