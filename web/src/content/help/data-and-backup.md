# 文件与备份建议

Markdown 容易迁移，但“文件在本地”并不等于“文件已经备份”。删除、磁盘故障和同步冲突都可能影响本地内容。

## 使用 3-2-1 思路

重要项目可以保留三份副本，使用两种不同介质，并让其中一份位于设备之外。实际方案可以是本机工作目录、外置硬盘快照和可信同步服务的组合。

## 定期做恢复演练

备份是否有效，应以“能否恢复”为准。定期把少量文件恢复到临时目录，检查正文、图片和文件名是否完整。

## 避免同步冲突

不要在多台设备上同时编辑同一文件。发生冲突时，先复制双方版本，再人工合并；不要急于覆盖或删除冲突副本。

## 导出与迁移

迁移前先关闭正在写入文件的应用，再复制完整项目目录。完成后随机抽查若干文档和附件，并保留旧副本一段时间。
