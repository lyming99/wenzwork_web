# 使用远程项目工作区

远程工作区让浏览器或移动端回到另一台设备上的真实项目。目标设备必须在线、已授权，并运行与 Host 兼容的 Device Agent。

## 进入设备

1. 打开“账户中心 → 远程设备”。
2. 从设备卡片确认在线状态、平台和 Agent 版本。
3. 点击设备卡片。浏览器会复用一个独立的“设备工作台”窗口，而设备列表仍留在账户管理页。
4. 在工作台左上角选择 Agent 已登记的项目；左侧可切换文件、终端和任务，下面是该项目的 AI 对话列表。

工作台右上角可展开辅助栏，在主工作区之外同时打开网页、阅读文件或跟进任务。再次点击其他设备卡片时会复用同一个工作台窗口，不会不断创建新窗口。

一个项目同时约束文件、终端、任务和 AI 对话。不要为了省事把整个磁盘登记成单个项目。

## 使用四类能力

- AI 对话：从左侧会话列表搜索、新建、打开或删除会话，在主区域继续消息、附件、计划、Goal、子 Agent 和工具审批；
- 文件：使用前进/后退、搜索、排序、列表/网格视图，浏览、预览、上传、下载、移动、重命名和保存项目范围内的文件；
- 终端：使用 Web 终端打开一个或多个真实交互式 PTY 标签页；未开放交互式终端的旧 Agent 会降级到受限只读命令模式；
- 任务：创建和编辑串行/并行任务与工作流，查看运行历史和日志，并执行启动、停止、重试、跟进、排期或验收。

高权限工具可能改写文件或执行命令。先使用最小权限，确认计划和目标目录后再批准写入或终端操作。

## 加密与在线边界

控制服务保存账户、设备、授权和连接路由所需的元数据。AI 对话正文、附件、文件内容、终端输入输出和完整任务日志在控制端与目标设备之间端到端加密；Relay 转发密文，不解密项目内容。

“设备在线”不等于某个项目永远可操作。Agent 停止、设备休眠、网络中断、Key 被吊销或项目权限变化都会让操作失败。连接恢复后先刷新设备状态，再继续任务；不要在不确定结果时重复执行有副作用的命令。

## 离开前检查

- 关闭不再需要的终端和文件传输；
- 确认长任务状态和最后一段日志；
- 高风险操作完成后收回临时权限；
- 不再使用的设备应先吊销，再从账户中删除；
- 重要文件仍应使用 Git、快照或独立备份。
