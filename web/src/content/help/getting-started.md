# WenzWork 快速开始

WenzWork 把 AI 对话、项目文件、真实终端和任务放在同一个项目工作区。你可以直接处理当前电脑上的项目，也可以连接一台持续运行 Device Agent 的远程设备。

## 第一步：选择使用方式

- 只处理当前电脑上的文件：前往[软件下载](/download)获取桌面端，选择本机模式。
- 要从浏览器或手机访问另一台电脑：先准备可登录的 WenzWork Host，再按[接入远程设备](/help/connect-remote-device)安装 Device Agent。
- 要自建完整服务：从[使用一键脚本部署 Host](/help/deploy-host-one-click)开始。

## 第二步：建立项目

在桌面端添加一个已有文件夹，或在远程设备详情中选择 Agent 已登记的项目。一个项目就是一条清晰的权限边界：文件、终端、任务和 AI 对话都围绕该项目展开。

建议：

- 不要直接把整个系统盘、用户主目录或下载目录作为项目；
- 先从只读或工作区写入权限开始，需要执行命令时再明确提升；
- 重要项目继续使用 Git、快照或独立备份，WenzWork 不替代备份系统。

## 第三步：开始工作

打开 AI 对话，描述一个可以验证的目标。Agent 会在当前项目范围内读取上下文、拟定计划并调用已授权工具；文件、终端和任务面板会保留可见的执行过程。长任务可以停止后继续，不必每次重新解释项目。

## 第四步：远程接续

远程使用时，先确认目标设备显示“在线”。控制服务负责身份、授权和连接路由；AI 对话正文、文件内容、终端输入输出与完整任务日志在控制端和目标设备之间端到端加密，不由中继节点解密。

下一步可以阅读[使用远程项目工作区](/help/remote-workspace)。
