# Markdown 常用写法

Markdown 使用少量纯文本符号表达结构。保留清楚的层级，比追求复杂排版更重要。

## 标题与段落

在文字前使用 `#` 表示标题。每篇文档通常只保留一个一级标题，下面依次使用二级和三级标题。

```markdown
# 文档标题

## 第一部分

这是一个自然段。
```

## 列表

无序列表使用短横线，有明确先后关系的步骤使用数字列表。

```markdown
- 一个要点
- 另一个要点

1. 第一步
2. 第二步
```

## 链接与强调

链接写作 `[显示文字](https://example.com)`。使用一对星号表示强调，使用反引号标记命令、文件名或短代码。

## 引用与代码块

引用段落以 `>` 开头。多行代码使用三个反引号包围，并在开头标注语言名称，方便阅读和高亮。

如果内容需要在其他平台发布，建议先用目标平台预览；不同渲染器支持的扩展语法可能不同。
